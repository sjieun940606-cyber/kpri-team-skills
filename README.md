# 한국가이던스 교육사업팀 스킬 모음

클로드코드에서 우리 팀 업무를 한 줄로 부르는 스킬 모음이에요. 학생·기관 자료나 개인정보는 들어 있지 않아요.

## 설치 (처음 한 번, 2분)

클로드코드를 연 뒤 **입력칸**에 한 줄씩 넣어요. (PowerShell이 아니라 `claude`를 친 뒤 나오는 입력칸이에요.)

```
/plugin marketplace add sjieun940606-cyber/kpri-team-skills
/plugin install kpri@kpri-team
/reload-plugins
```

설치 화면에서 **Install for you (user scope)** 를 고르면 어느 폴더에서든 써요.

## 쓰는 법

| 부르는 말 | 하는 일 |
|---|---|
| `/kpri:lecture 대상 시간 주제` | 강의안·활동지·강의 PPT: 대상·시간 확인 → 차시 흐름 승인 → 양식대로 만들기 → 시간·낱말·출처 점검 |
| `/kpri:report-team 양식` · `작성` · `대조` | 보고서 3인 팀: 지난 보고서로 양식 카드 → 양식대로 초안·1차 검증 → 결재 전 자료와 한 줄씩 대조 |
| `/kpri:result-report 사업명` | 운영계획서·커리큘럼·만족도로 결과보고서 초안 (계획 대비 실적 표) |
| `/kpri:proposal 사업명` | 제안요청서 평가항목·요구사항 뽑기 → 목차 → 초안 → 요구사항 대응표 |
| `/kpri:test-report 기관명 검사명` | 검사 원데이터 → 설정값 질문 → 계산표 → 보고서 초안 → PASS/FAIL 검수 |
| `/kpri:suui-search 지역 기간` | 대구·경북교육청 공개 화면·나라장터로 담당 학교 관련 수의계약 찾기 |
| `/kpri:counsel-check 폴더` | 상담일지 양식·표기 검수표 → 승인한 것만 정리본 (이름 지운 사본만) |
| `/kpri:school-docs 폴더` | 자료 한 벌을 {{학교명}} 템플릿으로 → 학교목록으로 한꺼번에 → 다른 학교 이름 남음 검사 |
| `/kpri:work-files 팀` | 반복 업무 인터뷰 → 8점 채점 → 6점 이상만 업무 파일로 |
| `/kpri:tool-check 주소` | SNS에서 본 스킬·플러그인을 설치 전에 검증 (진짜 저장소·설치 명령·위험 동작) |

스킬 이름을 몰라도 "보고서 초안 써줘", "이거 깔아도 돼?"처럼 말하면 알맞은 스킬을 클로드가 골라 써요.

## 업데이트

새 스킬이 추가되면 입력칸에 아래 줄을 넣어요.

```
/plugin marketplace update kpri-team
/reload-plugins
```

## 지킬 것

- 학생·학부모·강사 실명, 학번, 연락처, 상담 내용은 이름을 번호로 바꾼 사본으로만 작업해요.
- 결과의 숫자·이름·날짜와 해석 문장은 사람이 마지막에 확인해요.
- 이 저장소는 공개예요. 회사 자료·개인정보·비밀번호·API 키를 올리지 않아요.

더 자세한 사용법은 팀 '클로드 활용 가이드'를 보세요.
