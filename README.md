# 한국가이던스 교육사업팀 스킬 모음

클로드코드에서 우리 팀 업무를 한 줄로 부르는 스킬 모음이에요. 학생·기관 자료나 개인정보는 들어 있지 않아요.

## 설치 (처음 한 번, 2분)

클로드코드를 연 뒤 **입력칸**에 한 줄씩 넣어요. (PowerShell이 아니라 `claude`를 친 뒤 나오는 입력칸이에요.)

```
/plugin marketplace add sjieun940606-cyber/kpri-team-skills
/plugin install kpri@kpri-team
/reload-plugins
```

설치 화면에서 **Install for you (user scope)** 를 고르면 어느 폴더에서든 써요.

## 쓰는 법

| 부르는 말 | 하는 일 |
|---|---|
| `/kpri:report-team 양식` | 결재 통과한 지난 보고서로 우리 팀 '양식 카드' 만들기 (처음 한 번) |
| `/kpri:report-team 작성` | 지시 3줄 확인 → 양식대로 초안 → 스스로 1차 검증 |
| `/kpri:report-team 대조` | 결재 전, 초안을 자료·양식과 한 줄씩 대조 (새 대화에서) |
| `/kpri:test-report 기관명 검사명` | 검사 원데이터 → 설정값 질문 → 계산표 → 보고서 초안 → PASS/FAIL 검수 |
| `/kpri:tool-check 주소나 이름` | SNS에서 본 스킬·플러그인을 설치 전에 검증 (진짜 저장소·설치 명령·위험 동작) |

스킬 이름을 몰라도 "보고서 초안 써줘", "이거 깔아도 돼?"처럼 말하면 알맞은 스킬을 클로드가 골라 써요.

## 업데이트

새 스킬이 추가되면 입력칸에 아래 줄을 넣어요.

```
/plugin marketplace update kpri-team
/reload-plugins
```

## 지킬 것

- 학생·학부모·강사 실명, 학번, 연락처, 상담 내용은 이름을 번호로 바꾼 사본으로만 작업해요.
- 결과의 숫자·이름·날짜와 해석 문장은 사람이 마지막에 확인해요.
- 이 저장소는 공개예요. 회사 자료·개인정보·비밀번호·API 키를 올리지 않아요.

더 자세한 사용법은 팀 '클로드 활용 가이드'를 보세요.
