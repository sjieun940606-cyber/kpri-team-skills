# 수의계약 조회

대상: `$ARGUMENTS` (비어 있으면 담당 지역·학교급, 기간을 묻는다)

## 출처 (가장 완전한 순서)
| 출처 | 방법 | 담는 것 |
|---|---|---|
| 대구교육청 수의계약내역공개 `https://www.dge.go.kr/main/ir/selectPrvcntrList.do?mi=5310` | 위쪽 **「학교」** 탭(처음엔 '시교육청'이 선택돼 있음) → 연도·월(한 달씩) → 검색 구분 '제목' + 키워드, 또는 '기관명' + 학교 이름 → 엑셀다운로드 | 대구 학교 수의계약 전부(학교장터·소액 포함). 엑셀에는 금액·업체가 없어 필요한 건만 제목을 눌러 상세에서 확인. 1만 건이 넘으면 엑셀이 안 받아짐 |
| 경북교육청 K-에듀파인 수의계약내역공개 `https://www.gbe.kr/kedufine/ir/selectPrvcntrInfoList.do?mi=17696` | 기관 **「학교」** + 학교 이름 전체 + **금액 칸 0**(그대로면 100만 원 미만이 빠짐) + 기간 | 경북 학교 수의계약, 금액·업체 포함 |
| 나라장터 계약정보 API (조달청, 공공데이터포털) | `apis.data.go.kr/1230000/ao/CntrctInfoService` 의 용역(`getCntrctInfoListServcPPSSrch`)·물품(`getCntrctInfoListThngPPSSrch`), `inqryDiv=1`, `inqryBgnDate`/`inqryEndDate` YYYYMMDD(**한 번에 한 달까지**), `insttNm`에 교육청 이름, `numOfRows=999`, `type=json` | 큰 계약 위주. 인증키는 환경 변수 `G2B_API_KEY`(인코딩 키)에서만 읽는다 |

- 학교장터(S2B)는 로그인이 필요해 조회하지 않는다.
- 사이트에 부담을 주지 않게 요청 사이에 1~2초 쉬고, 필요한 달·학교만 조회한다.
- 인증키·비밀번호는 출력하거나 파일에 적지 않는다. 키가 없으면 나라장터는 건너뛰고 그렇다고 알린다.

## 거르기
- **포함 키워드**(계약명): 상담, 심리, 검사, 캠프, 진로, 학습, 인성, 적응, 또래, 정서 (사용자가 더 주면 추가)
- **제외**: 현장체험학습·체험학습, 버스·차량·전세·임차, 학습준비물·학습지 같은 단순 물품 구매. 애매하면 메모에 '확인 필요'.
- 담당 학교·지역만 남긴다. 학교 이름은 '○○고등학교'와 '○○고'를 같은 학교로 본다.
- 같은 계약이 여러 출처에 있으면(같은 학교·비슷한 계약명·계약일 10일 이내) 한 줄만 남기고 출처를 함께 적는다. 변경계약은 최신만.

## 결과
- 표: **학교 · 지역 · 계약명 · 분류(상담/심리검사/캠프/진로/학습/인성/적응/기타) · 계약일(YYYY-MM-DD) · 금액(숫자) · 업체 · 출처**
- 업체 이름에 '한국가이던스'가 들어가면 '우리 회사' 표시.
- 요약: 출처별·월별 건수, 금액 확인 건수, 우리 회사 건수.
- **작년 이맘때 계약 학교**를 물으면: 작년 기준 달과 다음 달에 계약한 학교 중 올해 같은 분류 계약이 아직 없는 곳을 따로 표로(확인 권장일 = 작년 계약일을 올해 날짜로). 실제 계약 여부는 학교에 확인하라고 적는다.
- 파일은 승인 후 `결과/수의계약_[대상]_[날짜].xlsx`로 저장한다. 원본 다운로드 파일은 고치지 않는다.
