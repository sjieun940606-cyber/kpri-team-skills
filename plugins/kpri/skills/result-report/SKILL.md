# 결과보고서

사업: `$ARGUMENTS`

## 1. 자료 확인 (먼저 묻기)
아래 네 가지가 어디 있는지 묻고, 받은 것과 없는 것을 표로 보여 준다. 없는 것은 그 칸을 `[자료 필요]`로 비운다고 미리 알린다.
| 자료 | 쓰는 곳 |
|---|---|
| 기존 결과보고서(같은 기관이나 같은 사업) | 목차·형식·문체 |
| 운영계획서 | 목표·대상·인원·일정 → 계획 대비 실적 |
| 커리큘럼(차시별) | 차시별 운영 내용 |
| 만족도 결과(엑셀) | 문항별 평균·주요 의견 |

학생·강사 실명, 연락처, 상담 내용이 보이면 작업 전에 지운 사본으로 할지 묻는다.

## 2. 초안
- **형식·문체**는 기존 결과보고서를 그대로 따른다(항목 순서, 종결어미, 숫자·날짜 표기).
- **계획 대비 실적 표**: 항목 | 계획 | 실적 | 차이 | 비고. 실적 숫자는 자료에 있는 것만.
- **차시별 운영 내용**: 커리큘럼 주제에 맞춰 실제 운영 내용을 정리. 자료에 없는 활동은 쓰지 않는다.
- **만족도**: 문항별 평균(소수 첫째 자리), 응답 수, 긍정 의견·개선 의견 각 3개 이내 요약. 계산은 초안 아래 '계산 근거'에 파일·시트·열을 적는다. 5점 척도에 6처럼 범위를 벗어난 값이나 빈칸이 있으면 먼저 알린다.
- 판단이 필요한 평가 문장(성과·개선점)은 `[확인]`을 붙이거나 `[직접 작성 필요]`로 비운다.

## 3. 마무리
- 초안을 먼저 보여 주고, 승인 전에는 파일로 저장하지 않는다. 승인하면 `결과보고서_[사업명]_초안.docx`로 저장한다.
- 마지막에 자료와 한 줄씩 대조하려면 `/kpri:report-team 대조`를 새 대화에서 쓰라고 안내한다.
- 한글로 옮길 때는 회사 서식 파일에 텍스트만 붙여넣기(Ctrl+Alt+V)를 안내한다.
