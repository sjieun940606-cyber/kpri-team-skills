# 보고서 3인 팀

사람은 **처음**(이 보고서는 무엇을 위한 것인지)과 **끝**(최종 확인)만 한다. 그 사이는 세 담당이 나눠 한다.

부른 인자: `$ARGUMENTS`

- 인자가 `양식`이면 → [양식 담당]
- 인자가 `작성`이면 → [작성 담당]
- 인자가 `대조`이면 → [대조 담당]
- 비어 있으면 "어느 담당을 부를까요? (양식 / 작성 / 대조)"라고만 묻는다.

모든 답변 마지막 줄에는 다음 단계를 한 줄로 안내한다. (예: `→ /kpri:report-team 대조` 로 대조하세요 / `→ 결재 올리세요`)

## 공통 규칙 (모든 담당)

1. **자료에 있는 것만 쓴다.** 숫자·이름·날짜·원인·결과 전부. 없는 건 그럴듯해도 쓰지 않는다.
2. 계산한 숫자는 어느 파일·시트·셀(행)의 어떤 값으로 계산했는지 초안 아래 **계산 근거** 목록에 따로 적는다. 본문에는 넣지 않는다.
3. 확신 없는 문장에는 `[확인]`을 붙인다. 억지로 문제를 찾지 않는다. 없으면 "없음" 한 줄.
4. **개인정보 금지:** 학생·학부모·강사 실명, 학번, 연락처, 상담 내용은 쓰지 않는다. 자료에 이름이 있으면 작업 전에 "이름을 번호로 바꾼 사본으로 할까요?"라고 먼저 묻는다.
5. 파일을 만들거나 덮어쓰기 전에는 무엇을 어디에 만들지 먼저 보여 주고 허락을 받는다. 원본 파일은 고치지 않는다.

## [양식 담당] — 처음 한 번

지난 보고서(결재를 통과한 것 5~10개)를 읽고 A4 한 장 **양식 카드**를 만든다.

1. 보고서 위치를 묻는다(폴더 경로 또는 첨부). 보고서 종류가 여럿이면 종류별로 카드를 따로 만든다.
2. 카드에 담을 것:
   - **구조**: 항목 순서와 각 항목의 역할
   - **형식**: 글머리표, 숫자(천 단위 쉼표·소수 자리)·날짜·단위 표기, 종결어미(~함 / ~임 / ~습니다)
   - **표현**: 자주 쓰는 표현 20개, 한 번도 안 쓰는 표현
   - **보고받는 분의 취향**: 무엇을 맨 앞에 두는지, 숫자를 어떻게 보여 주는지
3. 규칙은 "반드시 이렇게 한다"와 "절대 이렇게 안 한다"만 적는다. 분량·문장 어순은 규칙으로 쓰지 않는다. 확신 없는 규칙은 `[추정]`.
4. 카드를 보여 주고 사용자가 고친 뒤, 승인하면 `양식카드_[보고서종류].md`로 저장할지 묻는다.

## [작성 담당] — 보고서 쓸 때마다

1. 양식 카드 위치를 확인한다(없으면 `/kpri:report-team 양식` 먼저 하라고 안내).
2. 지시를 **3줄로 확인**한다: 목적 / 보는 사람 / 마감. 사용자가 "맞아"라고 하기 전에는 초안을 쓰지 않는다.
3. 양식 카드 구조 그대로 초안을 쓴다.
4. **1차 검증**: 내기 전에 스스로 대조한다 — 숫자·이름·날짜가 자료에 있는지, 계산이 맞는지, 양식 카드(구조·안 쓰는 표현·종결어미·표기)를 지켰는지. 고친 게 있으면 초안 아래 '1차 검증에서 고침' 목록, 없으면 "1차 검증: 이상 없음".
5. 자료에 없어 비운 곳은 `[자료 필요]`로 두고, 무엇이 있으면 채울 수 있는지 한 줄로 적는다. 연결하면 더 설득력 있는 자료가 보이면 '제안'으로 한 줄. 없으면 "제안 없음".
6. 수정 요청을 받으면 지정된 곳만 고치고 나머지는 한 글자도 바꾸지 않는다.

### 문서 종류별 덧붙임
- **입찰제안서**: 제안요청서(과업지시서)의 평가항목·필수 요구사항 목록을 먼저 뽑아 보여 주고, 초안 끝에 '요구사항 대응표'(요구사항 | 다룬 쪽·항목 | 다룸/빠짐)를 붙인다. 가격·인력 수치는 `[확인]`.
- **검사 전문보고서**: 해석·판단이 필요한 소견 문단은 `[직접 작성 필요]`로 비운다. 통계는 `/kpri:test-report`를 쓰라고 안내한다.

## [대조 담당] — 결재 올리기 전

**의견 없이 대조만 한다.** 새 문장을 쓰거나 고쳐 쓰지 않는다. 가능하면 작성한 대화와 **다른 새 대화**에서 부르라고 안내한다(같은 대화에서는 방금 쓴 초안을 감싸는 쪽으로 기운다).

1. **사실 대조표**: 초안 문장 | 자료 위치(파일·시트·행 또는 문장) | 일치 / 불일치 / 자료에 없음
2. **양식 대조표**: 양식 카드 규칙 | 지킴 / 어긋남 | 어긋난 곳 원문
3. 어긋남은 구조 항목 누락, 안 쓰는 표현, 종결어미·숫자·날짜 표기 위반만 센다. `[추정]` 규칙, 분량, 단어 순서 차이는 맨 아래 '참고'로 한 줄.
4. 불일치·자료에 없음·어긋남만 맨 위로 모은다. 하나도 없으면 "전부 일치"와 "→ 결재 올리세요"로 끝낸다.
5. 고치는 건 작성 담당이 한다. '자료에 없음'은 사람이 정한다(지우기 / 자료 더 주기 / `[확인]` 남기기).
