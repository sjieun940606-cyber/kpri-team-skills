# 학교별 자료 한 번에 만들기

대상 폴더: `$ARGUMENTS`

## 폴더 약속
```
표준자료/
├── CLAUDE.md            규칙·변경 기록
└── [검사명]/
    ├── 템플릿/           자리표시가 있는 원본 한 벌
    ├── 학교목록.xlsx      학교명·날짜·학년·담당자·인원…
    └── 결과/YYMMDD_학교명/
```
자리표시는 `{{학교명}} {{날짜}} {{학년}} {{담당자}} {{인원}}`처럼 **중괄호 두 겹**으로 쓴다.

## 1. 템플릿으로 바꾸기
- 원본 자료에서 학교마다 바뀌는 곳을 찾아 **쪽·줄 / 지금 글 / 바꿀 자리표시** 표로 먼저 보여 준다. 애매한 곳은 묻는다.
- 승인하면 그 자리만 자리표시로 바꾼 사본을 `템플릿/` 폴더에 `_템플릿` 이름으로 저장한다. 다른 글자·서식은 건드리지 않는다. 원본은 고치지 않는다.

## 2. 학교 목록
템플릿에 쓰인 자리표시 이름을 열 이름으로 하는 `학교목록.xlsx`를 만들고 예시 한 줄만 채운다. 날짜는 `2026. 9. 30.` 형식. 학교 담당 선생님 개인 연락처는 넣지 않는다.

## 3. 한꺼번에 만들기
- **처음엔 두 학교만** 만들어 보여 주고 승인받은 뒤 나머지를 만든다.
- 결과는 `결과/YYMMDD_학교명/` 폴더에 저장한다. 파일 이름에도 학교명·날짜를 넣는다.
- PPT·Word는 서식이 깨지지 않게 글자만 바꾼다. 한글(HWP)은 직접 만들지 않고 Word·PDF로 만든다.

## 4. 검사 (만든 뒤 반드시)
파일마다:
- 다른 학교 이름이 남아 있지 않은지(학교목록의 다른 학교명을 전부 검색)
- `{{`가 남은 빈 자리표시가 없는지
- 날짜·학년·인원이 학교목록 값과 같은지
결과를 **파일 / 검사 / PASS·FAIL / 고칠 곳** 표로 보여 준다. FAIL이 있으면 완료라고 하지 않는다.

## 5. 기록
템플릿을 고치면 `CLAUDE.md`의 변경 기록에 날짜·바꾼 내용을 한 줄 남긴다.
