# 상담일지 검수

대상: `$ARGUMENTS`

## 0. 시작 전에 (반드시)
- 회사 개인정보 방침상 AI로 검수해도 되는 자료인지 사용자에게 확인한다.
- **이름을 지운 사본으로만** 작업한다. 받은 원본은 그대로 두고, 사본에서 학생 이름·학교·연락처를 가명(학생A)으로 바꾼 것인지 묻는다. 실명이 보이면 작업을 멈추고 알린다.
- 상담 내용을 외부로 보내거나 다른 도구에 넣지 않는다.

## 1. 내 정리 규칙 확인
작업 폴더의 `CLAUDE.md`나 사용자가 준 규칙 문서를 읽는다. 없으면 우리 양식과 잘 정리된 예시 1건(이름 지운 것)을 받아 규칙을 추측한 뒤, 확실하지 않은 것(들여쓰기, 줄나눔 글자 수, 날짜·회기 표기, 파일 제목, 글머리 기호)을 하나씩 묻고 번호 붙인 규칙 문서로 정리해 `CLAUDE.md`에 저장할지 묻는다.

기본 규칙 예:
1. 양식의 항목과 순서를 따른다. 빠지면 '누락', 순서가 다르면 '순서'.
2. 상담 내용의 뜻은 바꾸지 않는다. 오탈자·띄어쓰기만 고치고 고친 곳은 모두 목록으로.
3. 날짜 `2026. 9. 30.`, 회기 `1회기` 형식.
4. 파일 제목 `YYMMDD_기관명_회기_강사명`.
5. 학생은 `학생A`처럼. 실명·연락처가 남아 있으면 고치지 말고 '실명 남음'으로 알린다.
6. 위기 표현, 앞뒤가 맞지 않는 내용은 고치지 말고 '담당자 확인'.

## 2. 검수표 먼저 (아직 고치지 않기)
파일마다: **파일명 / 양식 누락·순서 / 오탈자 후보 / 들여쓰기·줄나눔 / 파일 제목 규칙 / 실명 남음 / 담당자 확인**. 문제가 없는 칸은 '없음'.

## 3. 승인한 파일만 정리
- 사용자가 고른 파일만 규칙대로 정리해 `정리본/` 폴더에 규칙에 맞는 새 이름으로 저장한다. 받은 파일은 건드리지 않는다.
- 고친 곳 목록(파일 / 쪽·줄 / 고치기 전 / 고친 후)을 `정리본/수정내역.xlsx` 한 파일에 모은다.
- '담당자 확인' 표시한 곳은 그대로 둔다.

## 4. 강사 보완 요청 문구
'누락'이 있는 파일마다 강사에게 보낼 짧은 합니다체 문구 초안을 쓴다. 빠진 항목 이름만 적고 상담 내용·학생 정보는 넣지 않는다. 보내는 건 사용자가 직접 한다.
