# 외부 도구 검증

검토 대상: `$ARGUMENTS` (비어 있으면 무엇을 검토할지 묻는다. 캡처 이미지가 첨부되면 거기서 도구 이름·주소·설치 명령을 먼저 뽑아 보여 준다.)

**이 스킬은 읽고 확인만 한다. 검증이 끝나고 사용자가 승인하기 전에는 아무것도 설치·실행하지 않는다.**

## 1. 무엇을 주장하는지 정리
SNS 글이나 링크에서 아래를 뽑아 표로 보여 준다.
- 도구 이름, 종류(클로드코드 플러그인 / 스킬 / MCP 서버 / 웹 서비스 / 프롬프트 모음)
- 안내된 설치 명령(그대로 인용)
- 주장하는 효과(예: "토큰 절반", "코드 54% 감소", "공짜로 상위 모델")

## 2. 진짜 저장소인지
- 깃허브 주소가 있으면 `git ls-remote --heads https://github.com/소유자/저장소`로 실제로 있는지 확인한다.
- README를 `https://raw.githubusercontent.com/소유자/저장소/HEAD/README.md`로 읽는다.
- **이름이 같은 다른 저장소**가 있는지 생각한다. SNS 글의 주소와 README가 가리키는 공식 주소가 다르면 경고한다. 소유자 이름 철자를 한 글자씩 비교한다.
- 만든 곳이 공식(Anthropic, Microsoft 같은 회사)인지 개인인지 적는다.

## 3. 설치 명령이 맞는지
- 클로드코드 플러그인이면 저장소의 `.claude-plugin/marketplace.json`의 `name`(마켓 이름)과 `plugins[].name`(플러그인 이름)을 읽어, 안내된 `/plugin install 플러그인@마켓` 명령과 맞는지 비교한다. 다르면 올바른 명령을 적는다.
- 스킬이면 `SKILL.md`가 실제로 있는지, 설치 위치(`~/.claude/skills/` 또는 프로젝트 `.claude/skills/`)가 맞는지 본다.
- MCP 서버면 README의 `claude mcp add ...` 명령을 그대로 옮기고, 실행에 필요한 것(Node.js, Python, API 키)을 적는다.
- **어디에 치는 명령인지 구분해 적는다**: PowerShell에 치는 줄(`git clone`, `npx`, `pip`)과 클로드코드 입력칸에 치는 줄(`/plugin ...`).

## 4. 위험한 동작 점검
저장소 파일을 훑어 아래가 있으면 그 파일·줄을 인용해 보여 준다.
- **훅**(`hooks/`, `hooks.json`): 늘 자동으로 실행되는 동작. 무엇을 할 때마다 무엇을 실행하는지.
- `curl ... | bash`, 원격 스크립트 내려받아 실행, 전역 설치(`sudo`, `npm -g`), 설정 파일 수정
- API 키·비밀번호·토큰을 요구하거나 외부 서버로 파일·대화를 보내는 동작
- 스폰서·제휴 링크로 다른 유료 서비스 가입을 유도하는지
- 스킬·에이전트 수가 지나치게 많아(수십~수백 개) 클로드가 헷갈리고 사용량이 늘 수 있는지

## 5. 주장 확인
1단계의 주장마다 '맞음 / 과장 / 조건 있음 / 확인 불가'로 판정하고 근거를 한 줄씩 적는다. 예: "토큰 절반 → 문서마다 다름(표·그림은 사라짐)".

## 6. 판정과 우리 팀 메모
| 판정 | 기준 |
|---|---|
| ✅ 우리 팀 추천 | 진짜 저장소, 설치 명령 확인, 위험 동작 없음, 우리 업무(강의안·보고서·검사·상담·행정)에 바로 쓸 데가 있음 |
| ⚠️ 필요한 사람만 | 진짜지만 개발용이거나 조건(파이썬·Node.js·유료 계정·사용량)이 있음 |
| ⛔ 깔지 않음 | 가짜·사칭 의심, 위험 동작, 외부로 자료가 나감, 너무 커서 손해 |

마지막에 가이드에 붙여 넣을 수 있게 아래 형식으로 정리한다.

```
제목 — 한 줄 설명                         [판정 배지]
무엇을 하나: (두 문장 이내)
설치: (어디에 치는지 표시한 명령, 복사용)
우리 팀: (상담·검사·캠프·보고서 업무에서 어떻게 쓰는지 한 줄)
주의: (개인정보·저작권·사용량·가짜 저장소)
확인 기준일: YYYY-MM-DD
```

## 지킬 것
- 학생·참가자·강사 정보가 든 파일을 외부 도구에 넣으라고 권하지 않는다.
- 산 책·검사지로 만든 스킬은 남에게 나누지 말라고(저작권) 알린다.
- 확인하지 못한 것은 확인 못 했다고 쓴다. 추측으로 '안전함'이라고 하지 않는다.
