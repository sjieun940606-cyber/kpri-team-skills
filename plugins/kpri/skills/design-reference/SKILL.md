# 디자인 레퍼런스 공통 작업 지침

## 적용 범위
사용자가 공유한 Designrefs, oil-ui, 아이클릭아트 링크를 지속적으로 참고할 수 있도록 정리한 팀용 지침이다. 외부 모델을 재학습시키는 기능은 아니다. 설치된 실행 환경에서 디자인 작업을 할 때 적용한다.
최신 사용자 요청, 확정된 브랜드와 프로젝트 지침을 우선한다. 기존 파일의 기능과 정보 정확성을 지킨다. 이미 선택한 디자인을 이어가는 작업에는 새 시안 선택을 요구하지 않는다.
출처별 열람 상태와 활용 범위는 [sources.md](references/sources.md)를 읽는다.

## 작업 순서
1. 대상, 주요 행동, 출력 매체를 정한다. PPT/인쇄물/UI를 구별하고 실제 내용을 먼저 확인한다.
2. 필요한 항목의 레퍼런스 2~3개를 찾는다. 각 링크에 채택할 요소와 그 이유를 한 줄로 남긴다. 접근할 수 없는 화면을 본 것처럼 설명하지 않는다.
3. 새 디자인의 방향이 열려 있으면 같은 내용으로 서로 다른 2~3개 시안을 만든다. 정보 구조, 서체, 색, 이미지 배치를 실제로 달리하고 한 화면에서 비교 가능하게 제시한다. 사용자가 직접 진행을 맡겼으면 추천안을 선택하고 이유와 대안 미리보기를 남긴다. 작은 수정은 즉시 수정한다.
4. 선택한 규칙은 작업 폴더의 DESIGN.md에 기록한다. 브랜드 색, 글꼴, 크기 단계, 간격, 표/차트, 버튼과 상태 표시를 재사용 가능하게 정의한다.
5. 결과를 실제 출력 환경에서 점검하고 고친다. 화면 캡처를 직접 보지 못했으면 시각 검증 미완료를 명시한다. 기능 검증과 시각 검증 결과를 구분한다.

## 자체 품질 기준
- 한 장/화면의 주요 메시지와 다음 행동이 먼저 보이게 한다. 제목, 근거, 세부 내용을 글자 크기와 간격으로 구분한다.
- 한글은 단어와 의미 단위로 줄바꿈한다. 작은 글자로 억지로 맞추지 않고 내용과 배치를 조정한다.
- 확정한 브랜드 색과 도형 규칙을 이어 쓴다. 장식용 카드, 그림자, 테두리와 그라디언트를 자동으로 덧붙이지 않는다.
- 표에는 단위, 기준일, 합계와 출처를 붙인다. 비교 차트는 같은 축과 척도를 사용한다. 중요한 판단 근거를 장식 때문에 숨기지 않는다.
- 아이콘의 굵기와 모양을 통일하고, 상태는 색과 텍스트를 함께 표시한다. 버튼은 실제 행동을 설명한다.
- 웹 화면은 모바일/데스크톱, 긴 한글, 빈 데이터, 로딩, 오류와 성공 상태를 점검한다. 키보드 포커스와 모션 감소 설정을 지원한다.
- PPT는 실제 슬라이드 크기로 렌더링하여 넘침, 도표 가독성과 발표 흐름을 확인한다. 문서와 인쇄물은 페이지 경계, 폰트와 출력 여백을 확인한다.
- 숫자, 검사 해석과 기관 이름은 원자료와 대조한다. 디자인 개선을 이유로 내용을 임의로 바꾸지 않는다.

## 산출물과 보고
시안, 디자인 결정, 사용한 자료 링크와 확인한 화면을 해당 작업 폴더에 남긴다. 설치된 스킬 디렉터리에 프로젝트 자료를 쓰지 않는다.
완료 보고에는 선택한 방향, 변경점, 실제 검증, 남은 제약을 짧게 적는다.
