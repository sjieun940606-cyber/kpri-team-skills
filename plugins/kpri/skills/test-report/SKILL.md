# 검사 전문보고서

대상: `$ARGUMENTS`

## 0. 시작 전 — 개인정보
- 원데이터에 **이름·학번** 열이 있으면 먼저 멈추고 "이름·학번을 번호로 바꾼 사본으로 작업할까요?"라고 묻는다. 승인하면 사본을 만들고, 번호↔이름 대응표는 사용자 컴퓨터의 별도 파일로만 둔다(보고서 폴더에 넣지 않는다).
- 원본 엑셀·작년 보고서는 고치지 않는다. 결과는 새 폴더(`결과_[기관]_[연도]`)에만 만든다.
- 선별 명단(이름)이 보고서에 들어가야 하는지는 설정값에서 묻는다. 기본은 "번호만, 명단은 별도 파일".

## 1. 설정값 묻기 (한 번에 표로)
기관마다 요구가 다르니 아래를 질문하고, 답을 설정표로 정리해 승인받는다. 승인한 설정표는 작업 폴더의 `CLAUDE.md`에 기관별로 저장해 다음 해에 다시 묻지 않는다.

| 항목 | 기본값 |
|---|---|
| 비교 단위 | 학과별 (+ 단과대학별 / 학년별 / 성별 추가 여부) |
| 작년 대비 | 작년 원데이터가 있으면 척도별 증감 표 추가 |
| 선별 기준 | 척도 T 40 이하, SQ·AQ 지수 85 이하 (부정정서·무기력은 높을수록 문제면 60 이상) |
| 제외 대상 | 결과신뢰성 지표에 문제 있는 응답 포함 여부, 소수 인원 학과 처리(예: 10명 미만은 학과 보고서 미작성) |
| "가장 높은" 기준 | 선별 인원 / 선별 비율, 최소 인원 |
| 숫자 표기 | 소수 첫째 자리 반올림, 비율 합 100% 맞춤 |
| 명단 표기 | 번호만 / 별도 파일 / 보고서에 이름 |
| 결과 형식 | Word(.docx)·PDF, 그래프 색·글꼴은 작년과 맞춤 |

## 2. 원데이터 구조 확인
- 머리글이 여러 행(예: 위쪽 7행이 척도 이름)으로 나뉘어 있으면 합쳐서 열 이름을 만들고, 열 목록을 요약해 보여 준다.
- 원데이터에서 학과 목록을 자동으로 뽑아 기존 '실시 학과 목록'과 비교하고, **빠지거나 이름이 다른 학과**를 표시한다.

## 3. 계산표 (엑셀, 숫자는 모두 수식)
`계산표.xlsx`에 시트를 추가한다. 기존 시트와 수식은 건드리지 않는다.
1. **학과별 전체**: 모든 학과를 한 행씩 — 인원(남·여·전체), 척도별 평균, 선별 인원·비율.
2. **선별 명단**: 학과·척도별 번호를 한 칸에 쉼표로 잇고(TEXTJOIN), 옆 칸에 개수를 세서 선별 인원과 같은지 표시.
3. **틀 문장**: 작년 보고서의 학과별 소견 첫 문장들과 같은 틀의 문장을 수식으로("○○학과 학생 35명 중 …"). 숫자는 모두 셀 참조.
4. **검수**: 아래 5번 조건을 PASS/FAIL 수식으로.

## 4. 보고서 초안
- 목차·고정 글(검사 소개, 해석 지침, 개선 방법)은 작년 보고서를 그대로 따르고 기관명·연도·검사 기간만 바꾼다.
- 기본 목차: Ⅰ 검사 실시 및 분석 개요 → Ⅱ 검사의 구성 및 해석 지침 → Ⅲ 전체 통계(인원·척도별·적응도·종합소견) → Ⅳ 단과대학 분석 → Ⅴ 학과별 분석.
- 표·그래프·틀 문장은 원데이터로 새로 계산한 값만. 그래프는 이미지로 만들어 제자리에.
- 해석·판단이 필요한 소견 문단은 `[직접 작성 필요]`로 비운다.
- **먼저 목차, 학과 목록, 학과 한 개 샘플 페이지를 보여 주고 승인받은 뒤** 전체를 만든다.
- 결과: `보고서.docx`(한글에서 열어 최종 편집), `계산근거.xlsx`. HWP를 직접 만들지 않는다.

## 5. 자동 검수 (PASS / FAIL / 검수 필요)
보고서의 모든 숫자를 원데이터로 다시 계산해 대조한다. 기본 조건:
- 전체 인원 = 학과별 인원 합계, 원데이터 학과 수 = 학과 목록 수(누락 학과)
- 비율 반올림과 합계 100% (예: 54.1% + 45.8% 같은 어긋남)
- "가장 많은 / 가장 높은" 서술 = 실제 최댓값, 그리고 기준(인원·비율)이 각주와 같은지
- 선별 인원·비율 = 원데이터 재계산
- 목차 번호 연속(Ⅳ 다음 Ⅴ), 목차 항목 수 = 본문 항목 수
- 평균 계산에 들어간 인원(제외 대상 반영 여부)

결과는 `검수표.xlsx`와 요약 한 단락. FAIL은 맨 위로, 고칠 곳(쪽·표 번호)을 함께 적는다. 해석 문장은 담당 전문가가 최종 확인하라고 마지막에 안내한다.
