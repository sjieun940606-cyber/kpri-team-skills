# 강의안 만들기

요청: `$ARGUMENTS`

## 0. 새로 만들기인지, 고치기인지
- 기존 강의안·PPT를 주거나 "다듬어줘·바꿔줘·줄여줘"라고 하면 **고치기**다. 원본은 그대로 두고 사본으로만 작업하고, 바로 고치지 말고 아래 순서를 따른다.
  1. 전체를 읽고 장별 한 줄 요약
  2. 질문 5개 이내(대상·시간·바꾸는 이유·꼭 남길 내용·결과 형식)
  3. 장별 수정표(장 | 지금 | 바꿀 내용 | 이유)를 보여 주고 승인한 장만 고친다
- 그렇지 않으면 **새로 만들기**로 1번부터 한다.

## 1. 확인할 것 (한 번에 표로 묻기)
아직 정해지지 않은 것만 묻는다. 이미 말한 것은 다시 묻지 않는다.

| 항목 | 예 | 기본값 |
|---|---|---|
| 대상 | 초등 4학년 / 중1 / 학부모 / 교사 연수 | (꼭 물음) |
| 시간·회차 | 40분 1회 / 50분 3회차 | (꼭 물음) |
| 주제·목표 | 또래관계 — 친구 감정 알아차리기 | (꼭 물음) |
| 참고 자료 | 우리 강의안 양식, 작년 자료, 기관 요청 공문 | 있으면 양식을 그대로 따름 |
| 결과물 | 강의안(docx) / 활동지 / PPT / 셋 다 | 강의안 |
| 인원·장소 | 25명 교실 / 강당 | 교실 25명 |
| 디자인 | 기관 템플릿 / 한국가이던스 기본색 / 나중에 | 나중에(흰 배경) |

## 2. 목차·흐름 먼저 (승인 전에는 파일을 만들지 않는다)
- 차시마다 **도입 → 활동 → 정리** 흐름과 분 단위 시간표를 표로 보여 준다(차시 | 단계 | 분 | 활동 | 준비물).
- 활동은 대상 나이에 맞게, 한 활동에 한 가지 목표만. 시간 합계가 정한 시간과 맞는지 맨 아래에 적는다.
- 사용자가 "좋아" 하기 전에는 강의안·PPT 파일을 만들지 않는다.

## 3. 만들기
- **강의안**: 우리 양식이 있으면 항목 순서·표 모양·문체를 그대로 따른다. 없으면 [목표 / 대상·시간 / 준비물 / 진행(단계·분·활동·강사 말) / 유의점 / 확인 질문].
- **활동지**: A4 한 장, 이름 칸 없이 질문 3~5개와 적는 칸. 대상 학년이 읽을 수 있는 낱말로.
- **PPT**: 한 장에 메시지 하나, 글 5줄 이내, 뺀 설명은 발표자 메모로. 글꼴은 한 가지로 통일. 장 번호를 넣는다. 사진·그림은 출처가 분명한 것만, 없으면 '[그림: 설명]'으로 자리만 둔다.
- 여러 회차면 회차마다 파일을 나눠 `결과/[주제]_[대상]_[n]회차.docx`처럼 저장한다.

## 4. 스스로 점검하고 보여 주기
만든 뒤 아래를 표로 점검해 같이 보여 준다(항목 | 통과/확인 필요 | 위치).
- 시간 합계 = 정한 시간
- 대상에게 어려운 낱말
- 내가 주지 않은 통계·연구 결과·사례를 넣지 않았는지(넣어야 하면 `[자료 필요]`)
- 학생·강사 실명, 학교 이름이 들어가지 않았는지
- 검사지 문항 원문·저작권이 불분명한 자료를 쓰지 않았는지

## 지킬 것
- 확인되지 않은 통계·연구 결과는 넣지 않는다.
- 상담 사례를 예시로 쓸 때는 누구인지 알 수 없게 일반화한다(학교·반을 붙이지 않는다).
- 원본 파일은 고치거나 옮기지 않는다. 결과는 `결과` 폴더에만 저장한다.
- 마지막 줄에 다음에 할 일을 한 줄로 안내한다. (예: `→ 활동지도 만들까요?` / `→ PPT로 바꿀까요?`)
