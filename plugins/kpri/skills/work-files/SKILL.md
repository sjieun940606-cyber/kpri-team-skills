# 업무 파일 만들기

대상: `$ARGUMENTS` (비어 있으면 팀과 맡은 일을 한 줄로 묻는다)

## 1. 인터뷰 (한 번에 질문 하나)
아래 영역 순서로 반복 업무를 모두 적는다. 막연한 영역("영업하기")이 아니라 이번 주에 누가 하는 장면이 그려지는 한 동작으로 적게 되묻는다. 예: "지난해 캠프 계약 학교에 올해 일정 문의 메일 보내기".
학교 섭외·영업 / 견적·계약 / 홍보 / 사업 운영(캠프·강의) / 검사·상담 / 강사 관리 / 행정·정산
(사용자 팀에 맞게 영역을 바꿔도 된다. 바꿀지 먼저 묻는다.)

## 2. 채점
업무마다 네 가지에 0(아니다)·1(가끔)·2(그렇다)점:
- 자주 반복되나? / 규칙이 있나(신입에게 10분 안에 설명 가능)? / 디지털로 들어와 디지털로 나가나? / 조금 틀려도 괜찮나(초안·조사는 높고, 최종 금액·계약은 0)?
8점 만점 순위표를 보여 준다.
| 합계 | 판정 |
|---|---|
| 6~8 | 먼저 파일로 |
| 3~5 | AI 초안 + 사람 승인 |
| 0~2 | 사람이 계속(관계, 감각, 큰 결정) |

## 3. 업무 파일
6점 이상 업무마다 `.md` 파일 하나, 칸은 7개: **목적 · 시작 조건 · 입력 · 단계 · 결과물 · 완료 기준 · 예외**. 확실하지 않은 칸은 추측하지 말고 "확인 필요".
- 만들기 전에 폴더 구조(영역별 폴더)와 파일 목록을 먼저 보여 주고 허락받는다. 이미 있는 파일은 덮어쓰지 않는다.
- 학생·학부모·강사 실명, 연락처, 계좌, 비밀번호·API 키는 파일에 적지 않는다.
- 다 만든 뒤 파일 수를 세어 보여 주고, 가장 먼저 AI에게 넘길 영역과 이유를 세 줄로 알려 준다.

## 4. 다음 단계 안내
자주 쓰는 업무 파일은 스킬로 굳힐 수 있다고 안내한다(Anthropic 공식 `skill-creator`). 팀 공용으로 쓸 만하면 팀장에게 kpri 스킬로 추가를 요청하라고 알린다.
